## Goal
Calm fantasy music, wind/ambient layer, and a clean audio architecture others can call.

## Deliverables
- `Scripts/Audio/AudioManager.cs`: music crossfade, ambience loop, SFX play via pooled AudioSources, mixer exposed params `MusicVol`, `SfxVol`, `MasterVol`
- `Audio/Mixers/Main.mixer` with groups Master/Music/SFX/Ambience; volumes persisted via `SaveService` settings (or PlayerPrefs until T25 exists)
- Music: 1 gameplay loop (calm, airy, harp/pad), 1 menu/title loop; optional win sting
- Ambience: wind + distant chimes loop; 3D positional waterfall and lake loops (spatial blend 1, max distance 25 m) for T29 prefabs
- Sourcing: CC0/CC-BY packs (OpenGameArt, Kenney, Freesound CC0, Incompetech) — log each file in `Game/Assets/ThirdParty/LICENSES.md`; **or** user-supplied; **or** fallback procedural pad generated by a python script (`docs/audio/make_pad.py` → wav)
- Import settings: music streaming, SFX decompress-on-load, loop points clean
