## Goal
Turn the live Geometry Nodes assets into baked, validated, import-ready variants that Unity can pick by seed.

## Deliverables
- `Source/Blender/scripts/bake_plants.py`: for each kind and seed 1..6 → duplicate, apply modifiers, keep attributes, name `Plant_<Kind>_<NN>`, attach empties + proxies
- FBX exports in `Source/Blender/exports/` synced to `Game/Assets/Art/Models/Plants/` (24 files max, 4 kinds x 6, or one FBX per kind with 6 children)
- Validation report from `validate_export.py` for all variants saved at `docs/plant-validation.txt`
- Unity prefabs `Prefabs/Plants/Plant_<Kind>_<NN>.prefab` generated by an editor script (A2 provides the prefab builder in T11; coordinate)

## Steps
1. Run bake per kind as soon as each GN asset is stable; do not wait for all three.
2. Check each variant in Unity: scale, vertex colours, empties, proxies present.
3. Report the final list of prefab names to A2/A5 in the Handoff.

## Acceptance criteria
- [ ] All variants pass validation
- [ ] Each prefab loads in Unity with correct pivot at `Anchor`
- [ ] The same seed always bakes the same geometry (re-run bake, compare vertex counts)
